# Contributing

Thank you for considering a contribution.

## Before opening an issue

- Do not include private keys, server IP addresses, usernames, or `known_hosts` content.
- Include Windows version, PowerShell version, OpenSSH version, and anonymized error output.
- Confirm whether port `1080` is already occupied.

## Pull requests

- Keep changes focused.
- Do not change defaults that affect security without explaining why.
- Do not add real infrastructure data to examples or tests.
- Update README or documentation when behavior changes.
